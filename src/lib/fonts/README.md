# Fonts

`Archivo-Regular.ttf`, `Archivo-SemiBold.ttf` and `Archivo-ExtraBold.ttf` are
embedded in the auditor PDF so it matches the app's typography wherever it is
opened.

Archivo is by Omnibus-Type, released under the
[SIL Open Font License 1.1](https://openfontlicense.org), which permits
embedding in documents. Files are taken unmodified from Google Fonts.
